# سُرى للإعلام — الموقع

موقع سُرى بعد تحويله من صفحة ثابتة إلى تطبيق ويب يعمل على Firebase.

## ما الذي يعمل

| الصفحة | الوظيفة |
|---|---|
| `/` | الموقع الأصلي كما هو، والأكاديمية والمقالات. النصوص والصور تُقرأ من قاعدة البيانات |
| `/book` | حجز موعد: الخدمة، التاريخ، المكان، تحديد الموقع الحالي، التقاط صور بالكاميرا أو رفعها |
| `/login` | دخول وتسجيل بالبريد أو بحساب Google، واستعادة كلمة المرور |
| `/account` | حجوزات العميل وحالتها، وإلغاء الحجز، وتعديل البيانات |
| `/admin` | لوحة التحكم: الحجوزات، رسائل التواصل، العملاء، نصوص الموقع، صور الموقع، المقالات، الإعدادات |

نموذج التواصل في الصفحة الرئيسية يحفظ الرسالة في قاعدة البيانات ويُبقي خيار الإرسال عبر واتساب.

## كيف يتحدث الموقع

```
كلود يعدّل الكود ← جيت هاب ← Firebase App Hosting يبني الموقع وينشره تلقائيًا
                         ← GitHub Actions ينشر قواعد قاعدة البيانات والدوال
```

## الإعداد لأول مرة

1. **مشروع Firebase** على خطة Blaze، مع تفعيل Authentication (Email/Password وGoogle) وFirestore وStorage.
2. **App Hosting**: من Build ← App Hosting ← Get started، اربط حساب جيت هاب واختر المستودع `sura` والفرع `main`، والمجلد الجذر `/`. Firebase يملأ إعدادات الويب تلقائيًا أثناء البناء.
3. **القواعد والدوال** (مرة واحدة): من Project settings ← Service accounts ← Generate new private key. في المستودع على جيت هاب: Settings ← Secrets and variables ← Actions، أضف:
   - `FIREBASE_SERVICE_ACCOUNT`: محتوى ملف المفتاح كاملًا
   - `FIREBASE_PROJECT_ID`: معرّف المشروع
   ثم من تبويب Actions شغّل «Firebase backend». إلى أن تكتمل هذه الخطوة، انسخ محتوى `firestore.rules` و`storage.rules` يدويًا إلى تبويب Rules في الكونسول.
4. **حساب المشرف**: سجّل في الموقع من `/login`، افتح `/admin` وانسخ المعرّف الظاهر، ثم في Firestore أنشئ مجموعة `admins` ومستندًا بهذا المعرّف (بدون حقول، أو أي حقل).
5. **المقالات**: من لوحة التحكم ← المقالات اضغط «نقل المقالات» لنقلها إلى قاعدة البيانات.
6. **الدومين**: من App Hosting ← Settings ← Custom domain أضف الدومين، وضع سجلات DNS التي يعطيك إياها في هوستنجر.
7. **تنبيهات البريد** (اختياري): ثبّت إضافة Trigger Email from Firestore، وضع بريد التنبيهات في لوحة التحكم ← الإعدادات.

## بنية الملفات

- `src/app/` صفحات Next.js
- `src/legacy/` قالب الموقع الأصلي، والصور، والنصوص القابلة للتعديل
- `public/sura-app.js` سلوك الموقع الأصلي (السلايدر، الأكاديمية، محرر المقالات)، مربوط بـ Firebase
- `public/media/` صور الموقع الأصلية
- `firestore.rules`, `storage.rules` صلاحيات البيانات
- `functions/` الدوال على السيرفر: تنبيه عند كل حجز أو رسالة، ومكان الربط مع تطبيقات أخرى

## التشغيل محليًا

```bash
npm install
cp .env.example .env.local   # ضع إعدادات Firebase
npm run dev
```
