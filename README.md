# سُرى للإعلام — الموقع

موقع سُرى على Firebase (الخطة المجانية Spark)، مشروع `sura-8a91f`.

## الصفحات

| الصفحة | الوظيفة |
|---|---|
| `/` | الموقع الأصلي والأكاديمية والمقالات. النصوص والصور تُقرأ من قاعدة البيانات |
| `/book` | حجز موعد: الخدمة، التاريخ، المكان، تحديد الموقع الحالي، التقاط حتى ٤ صور بالكاميرا أو رفعها |
| `/login` | دخول وتسجيل بالبريد أو بحساب Google، واستعادة كلمة المرور |
| `/account` | حجوزات العميل وحالتها، وإلغاء الحجز، وتعديل البيانات |
| `/admin` | لوحة التحكم: الحجوزات، رسائل التواصل، العملاء، نصوص الموقع، صور الموقع، المقالات، الإعدادات |

## كيف يتحدّث الموقع

```
تعديل الكود ← دفع إلى main على جيت هاب ← GitHub Actions يبني الموقع
            ← ينشره على Firebase Hosting مع قواعد Firestore
```

الرابط: https://sura-media.com (والاحتياطي https://sura-8a91f.web.app)

## الخطة المجانية

- لا يوجد Cloud Storage، فالصور تُضغط في المتصفح وتُحفظ داخل مستندات Firestore (حد المستند 1 ميجا).
  صور الموقع المستبدلة في مجموعة `siteMedia`، وصور الحجز داخل مستند الحجز، وصور المقالات داخل نص المقال.
- لا توجد Cloud Functions، فلا تنبيهات بريد تلقائية. الكود جاهز في `docs/functions-for-blaze/` لو رُقّي المشروع لاحقًا.

## الإعداد لأول مرة

1. **مفتاح النشر:** Firebase Console ← Project settings ← Service accounts ← Generate new private key.
   في جيت هاب: Settings ← Secrets and variables ← Actions ← New repository secret،
   الاسم `FIREBASE_SERVICE_ACCOUNT` والقيمة محتوى ملف JSON كاملًا. ثم احذف الملف من جهازك.
2. **أول نشر:** تبويب Actions ← Deploy to Firebase ← Run workflow.
3. **حساب المشرف:** سجّل في `/login`، افتح `/admin` وانسخ المعرّف الظاهر، ثم في Firestore أنشئ مجموعة `admins` ومستندًا بهذا المعرّف.
4. **المقالات:** لوحة التحكم ← المقالات ← «نقل المقالات».
5. **الدومين:** Firebase Console ← Hosting ← Add custom domain، وضع سجلات DNS في هوستنجر.
